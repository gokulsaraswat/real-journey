# Contributing to Real Journey

This project will support a Git-based contribution flow.

## Planned contribution paths
1. Open an issue for feedback or content suggestions
2. Submit a pull request for code or content improvements
3. Use email for direct feedback when GitHub is not convenient

## Future policy
- Content changes should follow the taxonomy contracts
- Shared shell files require careful review
- Large work should be split into feature branches
